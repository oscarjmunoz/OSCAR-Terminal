# OSCAR UI Guide

## Purpose

Define baseline UI standards for the OSCAR decision workspace.

## Layout

- Header: global status and context.
- Sidebar: navigation and control surfaces.
- Main workspace: charts, cards, and decision panels.
- Status footer: operational and connection feedback.

## UI Principles

- Information hierarchy first.
- Explicit labels for analytical context.
- Stable component behavior across refresh cycles.
- Visual consistency for decision-critical states.

## Interaction Rules

- Timeframe context must be visible where analysis is shown.
- Decision output must include confidence or score indicators.
- Validation and performance blocks must not block core chart reading.

## Accessibility Baseline

- Legible contrast and typography.
- Keyboard-navigable critical controls.
- Predictable loading and empty states.
