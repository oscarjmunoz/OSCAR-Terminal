# ADR-001: Product-First Direction

- Status: Accepted
- Date: 2026-07-31

## Context

OSCAR needs a clear direction to prioritize value delivery over isolated technical optimizations.

## Decision

Adopt a product-first roadmap where technical tasks are validated by direct product impact.

## Consequences

- Roadmap and release notes align to user-facing outcomes.
- Architectural changes require explicit product justification.
- Documentation tracks why features exist, not only how they work.
