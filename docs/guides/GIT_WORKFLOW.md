# Git Workflow

## Branching

- Use one branch per objective.
- Name branches by purpose (feature/, hotfix/, docs/).

## Commit Strategy

- One logical change per commit.
- Use explicit conventional-style messages when possible.

## Recommended Sequence

1. Sync with remote base branch.
2. Create working branch.
3. Implement scoped changes.
4. Validate locally.
5. Commit and push.
6. Open PR with summary and impact notes.
