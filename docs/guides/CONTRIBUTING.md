# Contributing Guide

## Contribution Rules

- Open changes through feature branches.
- Add concise rationale in commit messages.
- Include documentation updates for architectural or workflow changes.

## Pull Request Checklist

1. Scope is clear and minimal.
2. No unrelated file modifications included.
3. Local validation is completed.
4. Documentation is synchronized with implementation.

## Review Expectations

- Prioritize behavior correctness and regression risk.
- Call out assumptions and open questions.
