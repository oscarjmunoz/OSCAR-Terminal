# OSCAR Roadmap

## Vision

Build OSCAR into a reliable institutional-style decision platform from alpha to 1.0.

## Milestones

1. v0.4.0-alpha: architecture stabilization and launcher reliability.
2. v0.5.0-alpha: deeper analytics and usability hardening.
3. v1.0.0: production-ready workflows and complete documentation baseline.

## Workstreams

- Architecture and engine consistency
- UI decision center maturity
- Data orchestration and validation quality
- Documentation and operating standards
