Version: Lite v0.5

# Visión

OSCAR no es una plataforma para analizar gráficos.

OSCAR es un Decision Center para traders.

TradingView se utiliza para analizar el mercado.

MetaTrader se utiliza para ejecutar órdenes.

OSCAR se utiliza para decidir.

---

# Nuestra misión

Ayudar al trader a responder una única pregunta.

¿Existe una operación de alta probabilidad en este momento?

La respuesta debe obtenerse en menos de cinco segundos.
