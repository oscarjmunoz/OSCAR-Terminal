# OSCAR Terminal

## Descripcion del proyecto

OSCAR Terminal es una plataforma de apoyo a decisiones de trading que integra backend, frontend y herramientas de operacion local.

## Requisitos

- Python 3.12 o superior
- Node.js 20 o superior
- npm 10 o superior
- Git

## Instalacion

1. Clonar el repositorio.
2. Instalar dependencias del backend.
3. Instalar dependencias del frontend.
4. Validar herramientas con el launcher.

## Ejecucion

Desde la carpeta launcher:

1. python launcher.py check
2. python launcher.py start

Para detener servicios:

1. python launcher.py stop
